# IT Security Now — logo files

Brand teal: `#13566f`. Prefer the SVGs on the web; use the PNGs where SVG isn't accepted (email, social, documents).

## svg/
| File | Use |
|---|---|
| `itsn-logo-linear-white.svg` | **Used on the website** (header + footer, dark navy background) |
| `itsn-logo-linear-teal.svg` / `-black.svg` | Horizontal logo on light backgrounds |
| `itsn-logo-stacked-white.svg` | Stacked logo on dark backgrounds (made from the black stacked file, colour change only) |
| `itsn-logo-stacked-teal.svg` / `-black.svg` | Stacked logo on light backgrounds |
| `itsn-icon-favicon.svg` | **Browser tab icon** — white mark on a rounded teal square |
| `itsn-icon-white.svg` / `itsn-icon-teal.svg` | Icon only, transparent background |

## png/
| File | Use |
|---|---|
| `itsn-logo-{linear,stacked}-{black,teal,white}.png` | Transparent-background logos |
| `itsn-icon-square-teal-bg.png` | Apple touch icon, social profile picture |
| `itsn-icon-square-white-bg.png` | Profile picture on light themes |
| `itsn-social-square-{teal,white}-bg.png` | Square social posts (icon + itsecuritynow.com) |
| `itsn-banner-{linear,stacked}-{teal,white}-bg.png` | 1920×1080 banners / slides / video cards |
